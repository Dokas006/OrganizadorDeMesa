# OrganizadorDeMesa

Sistema simples para organização de mesas e comandas utilizando Java puro.

## Funcionalidades

* Criar comandas de mesas
* Salvar nome do cliente
* Salvar número da mesa
* Salvar valor do pedido
* Listar todas as mesas criadas
* Mostrar o pedido com maior valor
* Mostrar a soma total de todos os pedidos

## Tecnologias utilizadas

* Java
* Programação Orientada a Objetos (POO)
* Arrays/Matrizes
* Listas

## Objetivo

Projeto desenvolvido com foco em aprendizado, prática de lógica de programação e evolução na linguagem Java.
